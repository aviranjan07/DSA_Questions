# 📘 DSA Questions (Java)

## 🚀 About This Repository

This repository contains my solutions to **Data Structures and Algorithms (DSA)** problems based on **PepCoding Level 1**.

I am solving problems topic-wise to build a strong foundation in DSA and improve problem-solving skills for coding interviews.

---

## 🧠 Topics Covered

📂 The repository is organized into the following topics:

* 📁 Getting Started
* 📁 Functions & Arrays
* 📁 2D Arrays
* 📁 Strings, StringBuilder & ArrayList
* 📁 Recursion & Backtracking
* 📁 Linked List
* 📁 Binary Tree
* 📁 Binary Search Tree
* 📁 Generic Tree
* 📁 HashMap & Heaps
* 📁 Patterns
* 📁 Dynamic Programming (Time & Space Complexity)
