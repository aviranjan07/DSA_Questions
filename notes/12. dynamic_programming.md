# 📘 Dynamic Programming (DP)

## 🔹 Idea

* Store results of subproblems

## 🔹 Approaches

* Memoization (Top-Down)
* Tabulation (Bottom-Up)

## 🔹 Problems

* Fibonacci
* Knapsack
* Longest Common Subsequence

## 🔹 Mistakes

* Not identifying overlapping subproblems

## 🔹 Tip

DP = Recursion + Storage
